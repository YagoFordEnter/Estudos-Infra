Como o Prof. Valiante cobra o conteúdo?

1. Visão "Infraestrutura de TI" (Ponta a Ponta)

Ele não cobra apenas definição solta: ele conecta Hardware → SO → Rede → Nuvem. Ex.: "Qual camada/protocolo atua quando um usuário digita uma URL?" (Síntese DHCP → ARP → DNS → TCP → HTTP).

2. Comandos Linux Reais & Modernos

No Nanocurso e nos slides ele destaca comandos atuais: ip addr, ip route, ip neigh, ss -tuanp, lscpu, free -ht, lsblk — e avisa que ifconfig/netstat são legados!

3. Comparações Arquiteturais Clássicas

Adora questões comparando: VM vs Container (Docker), TCP vs UDP, Switch (MAC) vs Roteador (IP), RAID 0 vs 1 vs 5 vs 10, IaaS vs PaaS vs SaaS e Multi-cloud vs Cross-cloud.
